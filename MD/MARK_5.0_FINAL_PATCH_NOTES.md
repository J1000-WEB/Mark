# MARK 5.0 Final Patch

## 판매전체상
- 하단 `전체 일정 목록` 테이블 삭제
- `서울 날씨` 행 유지
- 날씨는 `☀️ 맑음 / 30° / 22°` 2줄 표시 유지

## 매출 집계
- `글로벌_`, `기타_` 채널은 오프라인 매출 집계에서 제외
- 점포별 일/주/월 매출은 MARK_DB의 `일간매출(26년)` 시트 우선 사용
- `일간매출(26년)`은 A~G 합산 영역을 제외하고 H열 이후의 `오프라인팀` 채널만 집계
- `일간매출(26년)` 데이터가 없으면 기존 `Daily_Sales_History`로 fallback

## Snapshot / 속도 방향
- 대시보드 원본 직접 조회 최소화 방향 유지
- 상품/재고/RT 제안용 ERP 보조 데이터는 유지
- Store 매출 대시보드는 `일간매출(26년)` 기준으로 보정

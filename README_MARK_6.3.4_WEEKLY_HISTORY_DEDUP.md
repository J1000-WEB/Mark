# MARK 6.3.4 Weekly_History 중복 저장 차단 및 정리

## 원인
- `실시간 갱신`과 일부 자동 조회가 `Weekly_History`, `Weekly_Store_History`에 매번 append 처리되었습니다.
- 같은 기준 월요일의 품번/컬러/점포 데이터가 누적되어 셀 수가 급증했습니다.

## 수정
- 동일 기준 월요일 저장 시 기존 해당 주차 데이터를 삭제 후 최신 결과로 교체(upsert)합니다.
- 주간 화면에 `히스토리 중복 정리` 버튼을 추가했습니다.
- 정리 실행 시 다음 business key별 마지막 저장 행 하나만 유지합니다.
  - Weekly_History: 기준일 + 구분 + 스타일 + 칼라
  - Weekly_Store_History: 기준일 + 구분 + 스타일 + 칼라 + 점포명

## 운영
1. 배포 후 주간 대시보드에서 `히스토리 중복 정리`를 1회 실행합니다.
2. 이후 실시간 갱신은 기존 주차를 덮어써서 중복 셀이 증가하지 않습니다.
3. 화면용 주간 저장본은 계속 `Weekly_Snapshot`에서 기준 월요일별 1건을 유지합니다.

# MARK 6.3.1 주간 단일 Source / Snapshot 보정

## 핵심 수정
1. 기준일: `금주/전주!B2`의 월요일을 항상 사용합니다.
2. 주간 KPI/매장별 순위/호조·부진/월 누적: `MARK_DB / 일간매출(26년)`만 사용합니다.
3. 주간 화면의 실시간 갱신 및 스냅샷 저장은 `/api/weekly-history?dashboard=1` 단일 경로로 통일했습니다.
4. `실시간 갱신`은 저장하지 않고 원본만 다시 조회합니다.
5. `스냅샷 저장`은 현재 주차를 `Weekly_Snapshot`에 저장합니다.
6. 저장된 스냅샷은 기준 월요일별 최신 1건만 드롭다운에 표시합니다.

## 확인 순서
- `금주/전주!B2` 값 확인
- 주간 화면의 선택주차/분석기간/비교기간 확인
- `주차 · 집계 기준` 영역에서 `MARK_DB / 일간매출(26년)` 표시 확인
- 실시간 갱신 후 값 확인
- 스냅샷 저장 후 `주차 선택`에 기준 월요일 표시 확인

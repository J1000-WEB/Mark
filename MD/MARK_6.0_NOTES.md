# MARK 6.0

## 판매데이터 자동 생성 V1
- `판매데이터` 페이지를 MARK 6.0 기준으로 전환
- 예시 파일 `주간판매데이터_260622월.xlsx`의 품번/컬러 탭 구조를 최대한 동일하게 재현
- 예시 엑셀을 직접 읽는 방식이 아니라 MARK 데이터로 자동 생성
  - 매출: `MARK_HISTORY / Daily_Sales_History`
  - 상품/재고 기본값: `MARK_DB / 스타일별 채널별 입고판매재고현황`
  - 온오프 재고: `온오프재고현황` 시트가 있으면 자동 반영
- 주차 선택 기준은 월요일
  - 예: `6/22 월요일 기준` → 분석 `6/15~6/21`, 비교 `6/8~6/14`
- 품번 탭 / 컬러 탭 지원
- 점포별 주간 판매수량을 전체 펼침 컬럼으로 표시
- AI 분석은 제외하고, 엑셀 재현/자동 생성 구조에 집중

# MARK 6.3.3 - 주간 선택 주차 실시간 갱신 보정

## 수정 내용
- `실시간 갱신`과 `스냅샷 저장`이 현재 화면에서 선택한 주차를 API `week` 파라미터로 전달합니다.
- 예: `7/6 월요일 기준` 스냅샷 선택 상태에서 갱신하면 `6/29~7/5`를 다시 집계하며, 기본 B2 주차인 `6/29`로 되돌아가지 않습니다.
- `weeklyDataProvider`는 요청된 주차를 B2 기본 주차보다 우선하며, 원본 재생성도 같은 요청 주차로 실행합니다.
- 화면에 실제 집계 주차를 표시해 선택 주차와 집계 주차가 다른 문제를 즉시 확인할 수 있습니다.

## 데이터 기준
- 점포 매출: `MARK_DB / 일간매출(26년)`의 날짜 범위 합산
- 기본 주차: `금주/전주!B2` 월요일
- 선택한 스냅샷을 갱신할 때: 스냅샷의 `anchorMonday` 우선
